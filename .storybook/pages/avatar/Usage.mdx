## Overview

<GuideSection guide={guide} section="intro" />

### When to use

- Use an avatar wherever the admin shows who did something, beside that actor's name.
- Use it for actors that are not people too, such as an agent or the site, so a row of mixed actors lines up.

### When not to use

- Do not use it without the actor's name as text beside it.
- Do not use it as a profile picture that stands on its own, such as a large image on a user's page.
