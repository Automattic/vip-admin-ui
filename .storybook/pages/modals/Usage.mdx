## Overview

<GuideSection guide={guide} section="intro" />

### When to use

- Use a modal for a short task the user finishes or dismisses before going back to the page, such as adding an item or confirming a change.
- Use `useConfirm` for a yes/no question.
- Use an informational modal, with one Close button, for something the user needs to read before going on.

### When not to use

- Do not use a modal for a long form or a whole screen of settings. Use a settings screen instead.
- Do not use a modal to explain a single setting. Use `InfoTip` or `help` text in place.
- Do not use `window.confirm()`. Use `useConfirm` instead.
