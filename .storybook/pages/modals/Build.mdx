### Before you ship

The component does not supply these. Specify them in the design:

- Write the title. A dynamic or user-supplied title needs a one-line ellipsis.
- Choose the `size` for the content.
- Mark whether the modal is blocking. A blocking modal has no close button and ignores Escape.
- Write the error message for each way the action can fail.
