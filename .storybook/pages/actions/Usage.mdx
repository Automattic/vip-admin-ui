## Overview

<GuideSection guide={guide} section="intro" />

### When to use

- Use an `ActionRow` for every group of actions outside a modal footer.
- Use it for a single action too, so the action lines up with the groups around it.

### When not to use

- Do not use it in a modal footer. Use `ModalActions` instead.
- Do not use it for a settings screen's Save. Use `SettingsFooter` instead.
- Do not use it for an inspector panel's destructive control. Use `InspectorDangerZone` instead.
- Do not use it for actions on DataViews items. Use DataViews action descriptors instead.
