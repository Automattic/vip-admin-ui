## Overview

<GuideSection guide={guide} section="intro" />

### When to use

- Use a `SettingsSection` for each titled group of the screen's own settings.
- Use `SettingsFooter` for the screen's one Save.
- Use `SettingsLoading` while the screen fetches its settings.

### When not to use

- Do not use a section for a repeating entity the user acts on individually. Use a `Card` instead.
- Do not use `SettingsFooter` on a screen whose controls apply immediately. That screen has no Save.
- Do not use these in an inspector panel. Use `InspectorSection` instead.
