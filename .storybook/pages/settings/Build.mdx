### Before you ship

The component does not supply these. Specify them in the design:

- Mark where the screen saves: one Save in the footer, the last header action, or none.
- Write the help text for each control that needs it.
- Mark the heading level of every title on the screen.
- Write the loading label when the default string does not say what is loading.

The table does not show the following:

- `SettingsSection` takes `title`, `description` and `children`, and passes no other prop on.
- `SettingsFooter` takes `children` only. It holds the screen's one primary button.
- `SettingsLoading` takes `label` only. Without it, the row shows the `loading` string from `StringsProvider`.
