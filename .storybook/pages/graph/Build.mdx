### Before you ship

The component does not supply these. Specify them in the design:

- Write the words on every card, edge pill, exit, band and menu. The kit adds none of its own.
- Write screen-reader text for any state a card shows another way, such as its edge to End.
- Specify how the inspector changes an edge's ends. Dragging an end is pointer-only.
- Name each menu for what it acts on, such as "Step actions".
