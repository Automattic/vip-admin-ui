## Overview

<GuideSection guide={guide} section="intro" />

### When to use

- Use a graph canvas when the user edits a set of steps and the connections between them.
- Use it when where a step sits on the canvas means something to the user, such as a band it belongs to.

### When not to use

- Do not use it for steps in one fixed order. Use a list instead.
- Do not use it to choose where an edge goes by name. Put that choice in the inspector.
