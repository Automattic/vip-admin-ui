## Overview

<GuideSection guide={guide} section="intro" />

### When to use

- Use an inspector for the options of one selected item on a canvas, a graph or a list.
- Use it when the options change with the selection and the surface stays in view.

### When not to use

- Do not use it for settings that apply to a whole screen. Use a settings section instead.
- Do not use it for a task that needs the user's full attention. Use a modal instead.
