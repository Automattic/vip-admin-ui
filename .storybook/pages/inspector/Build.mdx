### Before you ship

The component does not supply these. Specify them in the design:

- Write the eyebrow and the title for each kind of item the panel shows.
- Mark which sections are collapsible, and write the summary each one shows while closed.
- Write the explanation for each read-out row that has an info tip.
- Write why the delete action is unavailable, for every case where it is.
